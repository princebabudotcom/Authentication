# IMPORTANT ARCHITECTURE ADVICE

Do NOT:

* Build everything in one controller
* Mix auth logic with AI logic
* Store AI prompts everywhere
* Skip security phase
* Start with chatbot first

Do:

* Build service-based architecture
* Separate auth/user/admin/AI services
* Create reusable middleware
* Use proper validation everywhere
* Make scalable folder structure from day 1
